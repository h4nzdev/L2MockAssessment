## 📖 Overview

**SSEQUEL** is an interactive, browser-native simulation platform designed for Tier 2 / Level 2 Technical Support engineers, store systems administrators, and IT support candidates. 

It provides real-world incident simulations across **Retail Point of Sale (POS) Fleets**, **Windows Automation (PowerShell)**, and **Network Diagnostics (ICMP/TCP)** with a 100% client-side relational SQL database engine (**AlaSQL**) and real-time streaming CLI terminal emulator.

---

## ✨ Key Features

- **⚡ 100% In-Browser In-Memory Database**: Powered by **AlaSQL** with zero backend, Docker, or external SQL server required.
- **🛠️ 3 Integrated Support Disciplines**:
  - **SQL Data Reconciliation** (AlaSQL queries, aggregate audits, multi-table joins).
  - **PowerShell CLI Automation** (Service restarts, process dumps, Windows event queries).
  - **Network Diagnostics** (Live ICMP ping traces, TCP socket probes, DNS lookups, route tracing).
- **📟 Real-Time Streaming CLI Terminal**:
  - Live packet-by-packet ping streaming with simulated round-trip latencies.
  - Asynchronous service stop/start sequences with PID allocation and health check probes.
  - In-terminal interactive CLI command prompt (`PS>` / `$`) for ad-hoc troubleshooting.
- **🎫 Enterprise ITSM Ticket Report UI**:
  - Displays realistic incident reports with ticket metadata (Reporter, Component, Priority, SLA Clock).
  - Clear narrative symptoms and technical acceptance criteria.
  - Mode switcher between **ITSM Ticket** and **Plain English** explanations.
- **✨ Custom Assessment & Mock Database Builder**:
  - Upload custom `.txt` files generated by AI to instantly create custom question banks.
  - Attach `.sql` files or paste schemas to unlock synchronized, context-aware AI prompt templates.
  - Optional **Google Gemini API** integration for automated AI question generation and evaluation.
- **🛡️ Dynamic Self-Healing Database Engine**:
  - Automatically synthesizes missing tables and columns referenced in custom AI questions so queries never crash with column/table errors.
- **📚 POS Runbooks & Architecture Documentation Explorer**:
  - Built-in documentation page with error code runbooks (e.g. `ERR-POS-4001`, `ERR-EFT-1002`), network topology diagrams, and SOP checklists.
- **🎨 Modern Dark & Light Mode**:
  - Dark default theme with custom CSS design tokens, glowing ambient lighting, and high-contrast accessibility signals (Green = Passed, Red = Error, Amber = Missing).
- **✨ GSAP-Powered Hero Experience**:
  - 2-column grid layout with 3D perspective-tilted live fleet radar dashboard and interactive number counters.

## 🎯 The 3 Core Disciplines

| Discipline | Environment ID | Console Title & Badge | Snippets Provided | Output Representation |
|---|---|---|---|---|
| **SQL Database** | `'sql'` | `SQL Query Editor` <br> `AlaSQL Dialect` | `SELECT`, `FROM`, `WHERE`, `INNER JOIN`, `GROUP BY`, `ORDER BY`, `COUNT(*)` | Interactive tabular `ResultTable` with rows and column headers |

## 📊 Curriculum & Scenarios

The platform includes **40 progressive real-world scenarios** divided into 4 difficulty tiers:

1. **Tier 1: Basic (Scenarios 1 – 10)**
   - Single-table `SELECT`, `WHERE` filtering, `AND`/`OR` Boolean logic, `IN` operators, status flags, and `ORDER BY` sorting.
2. **Tier 2: Medium (Scenarios 11 – 20)**
   - Multi-table `INNER JOIN`, `GROUP BY` aggregations, `COUNT(*)`, `SUM()`, `AVG()`, and error frequency rankings.
3. **Tier 3: Intermediate (Scenarios 21 – 30)**
   - `HAVING` clause grouping filters, correlated `NOT IN` subqueries, and `CASE WHEN` condition mapping.
4. **Tier 4: Advanced (Scenarios 31 – 40)**
   - 3-table and 4-table relational joins, un-synced sales during network partitions, conditional failure rate analysis, and fleet master triage matrices.

## 🛠️ Custom Assessment Builder

Users can create custom assessment banks without configuring any servers:

1. **Step 1: Choose or Provide Mock Database Schema**:
   - Select pre-built domain templates (**Restaurant POS**, **Healthcare Clinic**, **Hospitality Hotel PMS**, **ATM Banking Fleet**) or attach your own custom `.sql` file.
2. **Step 2: Copy the Synchronized Prompt to your AI**:
   - Copy the generated prompt and paste it into ChatGPT, Claude, or Gemini. The prompt instructs the AI to generate questions matching the exact schema and domain.
3. **Step 3: Attach or Paste the Generated `.txt` File**:
   - Upload the `.txt` file back into SSEQUEL to immediately launch the synchronized assessment in your browser.

## ⚡ Quick Start

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (or pnpm / yarn)

### Installation & Run

```bash
# 1. Clone or navigate to repository
cd PractialPractice

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## ⌨️ Productivity & Keyboard Shortcuts

- **`Ctrl + Enter` (or `Cmd + Enter`)**: Execute and validate the current query/command.
- **Snippets Bar**: Click any keyword or cmdlet snippet (e.g. `SELECT`, `Restart-Service`, `ping -n 4`) to insert directly at the cursor position.
- **Practice Unlock**: Toggle *Practice Unlock: ON* to freely navigate between questions without strictly passing previous ones.
- **Reset Template**: Click *Reset* to restore the starter template for the current scenario.
- **Navigator**: Open the multi-question navigator modal to jump directly to any scenario.
